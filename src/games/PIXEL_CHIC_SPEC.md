# Task: Replace Pebble Jump with PIXEL CHIC — Retro Dress-Up Game

Redesign Machine #2, currently called **PEBBLE JUMP**, into a fully interactive retro pixel-art dress-up game called **PIXEL CHIC**.

Keep the original Retro Arcade theme, pixel-art aesthetic, arcade cabinets, other minigames, and shared functionality.

## 1. Character Selection

Allow players to select either a **Girl** or **Boy** character.

Both characters must have extensive customization, including:

- Skin tones from light to deep brown
- Eye shapes and colors
- Eyebrows, lips, and facial expressions
- Different body silhouettes
- Hairstyles and hair colors
- Clothing and accessories

Include hairstyles such as afros, 4C natural hair, braids, locs, twists, fades, curly hair, straight hair, ponytails, and buns.

Allow players to switch between boy and girl characters. Clothing should not be unnecessarily gender-restricted.

## 2. Retro Fashion Wardrobe

Create a cute, interactive wardrobe with mix-and-match clothing.

Include tops, bottoms, dresses, pants, jackets, shoes, hats, jewelry, glasses, bags, and hair accessories.

Include multiple fashion aesthetics:

- Coquette and Shoujo
- Y2K and McBling
- Old Money and Preppy
- Streetwear and Skater
- Dark Academia
- Gothic and Grunge
- Soft Boy
- Fairycore
- Vintage and Formal

Allow players to change individual clothing pieces, remove items, and apply complete outfit presets.

Ensure clothing layers correctly on the character.

## 4. Game Interface

Design a beautiful retro pixel-art dressing room.

The interface should feature:

**Left:** Character customization options.

**Center:** Large full-body character preview with animations.

**Right:** Clothing wardrobe, outfit collections, and Halloween costumes.

Include buttons for:
- Randomize Character
- Reset Outfit

Support desktop mouse and keyboard controls.

## 5. Gameplay

Include two modes.

**Free Dress-Up:** Players can customize characters and create outfits without time limits.

**Fashion Challenge:** Give players themes such as Halloween Party, Y2K Pop Star, Royal Ball, Gothic Romance, Streetwear, and Cozy Autumn.

Players create an outfit matching the theme and receive a score based on outfit coordination and theme compatibility.

Add a retro runway animation and celebrate successful outfits with sparkles and confetti.
